OPEN ONCOLOGY RESEARCH · TCGA LUAD

What does the data actually support?

We tested whether tumor molecular measurements improve survival modeling beyond basic clinical information. This dashboard shows the cohort, the held-out results, and the limitations—without turning an exploratory model into a patient risk calculator.

! CURRENT EVIDENCE

Not ready for individual risk prediction.

Neither added TMB nor RNA improved held-out survival ranking. At one and two years, none of the fitted models beat a simple constant-probability reference on prediction error.

Research and educational use only. Not a clinical decision tool.

01 / THE STUDY

One cancer type. One clear question.

Public TCGA lung adenocarcinoma data, curated by cBioPortal. Each eligible patient contributes one primary tumor sample.

Loading cohort summary…

Overall survival is measured from diagnosis. Death is the event; people still living at last follow-up are treated as right-censored, not as if they had survived indefinitely.

Use the controls to explore clinical data plus tumor mutational burden (TMB) or RNA gene activity. Each comparison uses its own matched patient group; scores across the two groups should not be directly compared.

03 / HOW IT WORKS

The test data stayed out of the classroom.

We built a reproducible workflow so the final scores reflect new, unseen patients—not answers accidentally shown to the model during training.

01

Define the cohort

Validate public clinical files, keep primary lung adenocarcinoma tumors, and record every exclusion.

02

Keep a test set aside

Set aside 20% of patients before fitting. Compare each pair of models on the same held-out patients.

03

Learn only from training

Fill missing values and scale features inside each training fold. For RNA, select genes and compress them there too.

04

Check two kinds of error

C-index checks ranking. One- and two-year Brier scores check survival probabilities against a simple reference.

↗

Everything is reproducible from pinned, checksum-verified public inputs. Read the run instructions.

04 / WHAT THIS CANNOT SAY

A research result is not a medical answer.

Small held-out groups, incomplete follow-up, and a single retrospective cohort mean these findings need external validation. Stage and molecular data may not have been available at diagnosis. We cannot correct for delayed entry into sequencing with the current files.

This work does not measure treatment benefit, establish gene biomarkers, or support clinical decisions for an individual.
